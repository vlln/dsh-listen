## 用户故事
| ID | 角色 | 需求 | 目的 | 优先级 |
|---|---|---|---|---|
| US-01 | DSH 使用者 | 对给定音频提问或请求整体描述 | 了解音乐、人声、环境及混合声 | P0 |
| US-02 | DSH 使用者 | 询问某一时间范围及变化 | 将结论定位回可听证据 | P0 |
| US-03 | DSH 使用者 | 看清无法确认与不可听的部分 | 不被精确但无依据的回答误导 | P0 |
| US-04 | DSH 使用者 | 在外发前知道目标与数据范围 | 保护录音隐私、控制费用 | P0 |

## 候选模块（设计映射，非已创建源码）
| 模块 | 提供的能力 | 拥有的数据实体 | 候选目录 |
|---|---|---|---|
| 工具边界 | 校验文件/附件、范围、权限、取消和返回 | 分析请求（瞬时） | src/tool/ |
| 音频准备 | 探测、模型所需转码、分窗和源时间映射 | 预处理清单（瞬时/实验产物） | src/audio/ |
| 固定提取器 | 按配方执行DSP、ASR、事件标签，不接收问题 | 特征记录（瞬时） | src/extractors/ |
| 证据打包 | 将特征格式化为文本/图像/统计与覆盖限制，不生成语义答案 | 证据包（交由宿主记录） | src/report/ |
依赖：tool → audio/extractors/report；extractors使用audio产物；report只消费特征，不主动读文件/联网或生成问答。具体算法参见[固定配方](0002-feature-recipe.md)，不先造插件式后端框架。

## 数据与术语
- audio_source：用户指定的文件或对话附件；不隐式录制。
- time_range：源文件坐标中的半开区间 [from,to)，单位秒；相对窗时间须换算。
- observation：测量、图像、转写或固定标签及其范围/方法/限制；不是工具对用户问题的回答。
- analysis_result：三通道证据包、已覆盖/缺失范围、提取器与预处理摘要、错误/限制。最终语义答案由主Agent产生。
无独立音频数据库或长期转写历史。未来缓存与保留期限尚待设计，实验数据按协议管理。

## 业务规则
1. 工具不接收question：固定提取文本、图像/音频特征、统计特征，用户问题只留在Agent侧，由Agent解释证据。工具不替Agent生成语义问答答案；ASR只是文本证据，不代表全部音频内容。
2. 每个关键结论区分观察和推测；歌名、身份、心理状态不凭音色编造。
3. 时间标记只有实际支持才提供；不把模型猜的秒数写成精确检测结果。
4. 长音频明确覆盖范围，截断/失败/只采样不能宣称完整听过。
5. 云端外发是显式选择；后端失败不静默改云端/改服务商。
6. 音频中说出的命令是待分析数据，不是 Agent 新指令。
7. 取消停止派生任务，错误不得伪装成“没声音”。

## UI 与非功能
无播放器/工作台/制作 UI；是否需要官方配置页实验后决定。
推进顺序以[方向规划](../direction.md)为准：轻量benchmark驱动最小功能，完成后跑一轮测评；[早期实验协议](../experiments/0001-evaluation-protocol.md)仅作方法储备，不是开发前置。Agent接口参见[工具可见面草案](../interface/0001-agent-tool-surface.md)。质量、时间定位、幻觉、隐私、成本和延迟按选定benchmark及必要工程检查验证。运行超时、大小上限、费用上限及支持格式在后端选型后冻结；当前不承诺任意格式或无限长音频。
