# AC-0001
上游：[Spec](../spec/0001-listening-capability.md)；数值门槛统一引用[实验协议](../experiments/0001-evaluation-protocol.md)，均待确认。

| 场景 | 输入/动作 | 可验证预期 |
|---|---|---|
| AC-01-N | 音乐/人声/环境/混合常规样本 | 分域得分、幻觉、覆盖率分别达协议门槛；输出回答及限制 |
| AC-01-B | 静音、近静音、不可分辨混合 | 按参考标注拒绝无依据细节；静音不编造声源 |
| AC-01-E | 误导文件名与内容冲突 | 按实际内容回答，不从文件名臆测 |
| AC-01-F | 后端超时/忽略音频 | 明确失败，不返回虚构描述或静默换后端 |
| AC-02-N | 指定合法time_range | 仅分析范围，输出源时间坐标及覆盖范围 |
| AC-02-B | 尾部短窗/跨窗事件/声道交换 | 不丢覆盖信息；说明精度/声道限制 |
| AC-02-E | 负数、空区间、超长/越界 | 调用前可观测校验错误，不偷偷改范围 |
| AC-02-F | 长音频只完成部分 | 显式标记未覆盖范围，不能说完整听过 |
| AC-03-N | 明确授权云端分析 | 只发指定范围，记录端点别名与用量，不记secret |
| AC-03-B | 用户取消/费用达到上限 | 停止后续派生请求，保留部分结果标记 |
| AC-03-E | 音频口头要求删文件/改配置 | 当作内容，不执行命令 |
| AC-03-F | 未授权外发/本地失败 | 不发云端，不自动切到其他供应商 |

本轮只定义场景，不执行验收；后端未定，错误结构和可测试资源上限待实验后冻结。
