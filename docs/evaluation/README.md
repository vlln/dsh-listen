# 评测文档

本目录保存可分发成绩、协议与操作约定；脚本按[评测入口](../../evaluation/README.md)导航。历史成绩只能按其模型、配置与协议条件解释，不代表当前默认已验收。

| 直接子级 | 状态 | 说明 |
|---|---|---|
| [experiment-preparation.md](./experiment-preparation.md) | 准备协议 | 三臂矩阵、冻结校验与盲态/评分分离。 |
| [results.md](./results.md) | 成绩依据 | 固定题单对照、配置条件及未评测边界。 |
| [thin-adapter.md](./thin-adapter.md) | 执行指南 | 创建运行、批量执行与适配器职责。 |
| [batch-layout.md](./batch-layout.md) | 批次约定 | 输入分离、产物、截止与失败处理。 |
| [preset-usage.md](./preset-usage.md) | 装配规范 | 默认工具面、persona 与隔离限制。 |
| [summary-format.md](./summary-format.md) | 离线评分 | 输入输出、指标与官方评分差异。 |
| [dataset-admission.md](./dataset-admission.md) | 数据准入 | 媒体来源、版本及使用边界。 |
| [experiments](./experiments/README.md) | 实验记录 | 历史协议、来源与对照设计。 |
