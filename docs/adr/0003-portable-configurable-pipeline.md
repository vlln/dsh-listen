# Pipeline修订：参数可解释、默认安装轻

来源：用户进一步明确：将音频变成语言模型可理解的特征，封装多步操作减少调用；Agent应理解参数并可调部分参数。安装容易、安装包小是面向用户分发的核心约束；ASR允许API或可选本地模型。

本稿取代[ADR-0002](0002-extraction-stack.md)的“默认Python+TF+本地模型”和接口只许时间范围的限制，不否定其算法/单位设计。当前仍未实现、安装或验证。

## 1. 保持的边界
不设question/prompt，不把用户题目或选项送给提取器；工具返回证据，主Agent推理。Pipeline可有有界参数和版本固定的默认值，不等于必须固定全部参数。不追求“特征尽量多”的数量，而优先可解释、互补、可消费且成本合理的信息。

## 2. 三层参数责任
| 层 | 内容 | 谁决定 |
|---|---|---|
| 不变量 | 原信号保留、单位、源时间、FFT缩放、缺失/错误含义、权限 | 实现契约；Agent不能改变定义 |
| 分析参数 | 范围、提取项目、频谱时频折衷、显示频段、声道呈现 | Agent在允许值内选择，返回实际生效参数与解释 |
| 部署策略 | 本地/API供应商、凭据、下载、外发同意、价格/资源上限 | 用户设置/宿主；Agent不能用参数授权或改供应商 |

## 3. Agent可见参数提案
沿用source_path/attachment_id/from/to；新增以下受限参数，不增加自由文本：

| 参数 | 默认/允许值 | 影响与边界 |
|---|---|---|
| features | [signal,transcript,events]；非空、去重枚举子集 | signal=元数据+图像+统计，transcript/events依用户配置运行；显式选子集不称完整能力 |
| spectral_detail | balanced；transient/balanced/tonal | 控制时频折衷。暂拟n_fft=1024/2048/4096、hop=n_fft/4，periodic Hann；有效窗长秒数随分析sr返回 |
| frequency_range_hz | 全部可用频段；[min,max] | 只裁可视频段，不悄悄修改全带统计/ASR/events；越过Nyquist报错，不能生成不存在的高频 |
| channel_view | separate；separate/power_mean | 仅图像呈现；power_mean平均各声道功率，不先平均波形。逐声道统计仍保留，ASR独立mono限制照报 |

首次调用给紧凑概览，但理解过程允许且预期可能多轮：Agent根据上一轮证据自主缩窗/选特征/换分辨率。单次Pipeline封装处理步骤，而非将整个理解过程压成一次调用；不强制先probe，也不强制每次先概览。第一次返回duration/sr/Nyquist及有效配置和允许值。发生参数错误可给技术元数据与修正建议，不付费处理；不能借错误响应绕权限。

spectral_detail与frequency_range不影响未请求特征或非图像统计（F08固定balanced全频，图像变化不让同一统计名偷偷改变定义）。图像标注window_ms/hop_ms、实际可见频带和信息损失；所有缓存身份纳入有效参数。

不暴露任意FFT/阈值/模型参数，以免参数面过载；只有真实开发任务表明预设不够才增补。低能量阈值首版仍固定并返回，不允许Agent通过改阈值制造“无人声”结论。

## 3b. Agent主动观察循环
- Agent决定“是否继续、看哪个范围、选择哪些特征和分析尺度”，不向工具传语义问题。Pipeline内部只执行本次确定的处理图，不自动语义追问或无限重试。
- 返回analysis_id、源内容hash、源时间覆盖、requested/effective参数、各特征status/限制，以及可用能力与允许调节范围；analysis_id仅为追溯/对照，不新增必须依赖内存状态的输入selector。
- 例：全段默认概览→发现12–15秒存在短促重复能量峰→Agent对11–16秒请求signal、transient、相应频段→若需要语言内容，再请求该范围transcript。每一步都由Agent根据返回证据选择，工具不替它判断声源。
- 缩短范围提升图像显示密度，改长窗提升频率分辨率，但牺牲时间分辨率；把显示放大与新增测量分开。重复同参数/同音频的相同证据不是独立确认；改参数也不能据“多数结果”投票认定事实。
- 不承诺缩窗总会改善：ASR/事件模型上下文减少可能变差，FFT边界与相对dB参考也会改变。必须返回上下文边界、pad/显示参考；跨次比较不能拿各自相对峰值图当绝对响度变化。
- 缓存按组件和有效依赖参数分解：只改显示频段/声道视图不重跑ASR/events；同范围同模型转写复用。局部裁剪整段ASR仅在时间对齐可用时作为复用结果，必须标reuse而非重新推理；真正缩窗重跑标明context_changed。
- 总预算由用户/宿主设置，Agent在限额内自主迭代；不写死必须一次或三次。预算覆盖总调用、API实际请求/费用、累计时长和资源；命中预算返回明确状态，不偷换后端。Agent停止条件是证据足够、现有方法无法判定或预算耗尽，不强制给确定答案。
- benchmark允许同样的自适应循环并冻结参数允许集/总预算，而不是要求所有题调用次数相同。记录整条调用轨迹与缓存命中、实际计算/外发成本；单次概览可作为以后可选消融，不作为第一轮新增长实验要求。

## 4. 轻核心与可选提取器
### 默认核心（技术候选，不是已确认包大小）
- Node宿主已有，优先Node/TS编排；尽量选少依赖的FFT、数值计算与PNG编码组件。不默认要求用户安装Python、TensorFlow、Torch、Matplotlib、编译器或模型。
- 解码优先系统FFmpeg/FFprobe，检测到即复用；缺少时给用户明确选项：可选按平台下载校验过的预构建包，或手动安装。不能默默下载，不能让“npm包小”掩盖首次安装总量；无FFmpeg不能谎称支持所有压缩格式。
- Native/WASM DSP或解码是候选，不先手写复杂DSP去省包；需核实跨平台、许可证、维护、包闭包大小、图像性能和与参考公式的一致性。尚未选npm依赖，不宣称JS实现必然更小更好。
- [特征配方](../spec/0002-feature-recipe.md)为数学参考；其中Python库不再是默认运行时要求。必须经合成信号验证再用轻实现替代，不能因同名FFT就认为结果相同。

### 可选能力
| 提取器 | 模式 | 安装/使用取舍 |
|---|---|---|
| ASR | 用户配置的API | 无本地权重；有外发/鉴权/费用/网络依赖，只转写不问答；首版优先核实一种明确协议而非全供应商 |
| ASR | 可选whisper.cpp+用户选模型 | 离线；二进制和权重独立按需下载/复用，不绑small非量化为默认；量化质量另测 |
| events | 可选轻推理运行时+固定分类模型 | 优先核实已有TFLite/ONNX等合法可分发制品，不默认装完整TF；转换等价性、预处理与标签时间映射都要核验 |
| events | 可选真实事件分类API | 仅在找到固定词表/可核结果的明确服务后支持，不假定ASR API自带事件分类；不以音频LLM问答冒充分类 |

提供方映射到相同证据容器，但能力/字段可不同。API不支持时间或诊断分数则null+原因，不能伪造本地同等输出。用户选择的后端失败不静默云端fallback。

## 5. 完成状态修订
整体status相对于本次features计算，另外列available_features/missing_features/requested_features。例如用户明确只选signal，signal成功可complete；默认请求三项而ASR/events未配置，应返回partial并明确缺失，不自动下载/上传。组件间失败隔离，基础图像统计不因无key不可用。

benchmark锁定部署配置、features与Agent调参规则/总调用预算；缺失events/ASR的轻配置不混作完整配置成绩。性能比较计总安装/运行/外发成本，不只看工具响应速度。

## 6. 安装验收必须新增的指标
分别量测而非臆测：npm压缩包、解压包、安装后全部依赖、按平台原生组件、首次可用下载量、模型缓存、稳态内存；区分冷装/复用系统工具。记录安装步骤、是否需要编译/管理员权限、支持系统/架构、升级卸载和离线可用性。

首版不先指定虚假MB目标；候选核实后给用户一张功能×安装增量表再取舍。配置API不是“零配置”，复用系统FFmpeg也不是“零依赖”。

## 7. 实施前待核
- 轻核心依赖与跨平台体积/许可证/渲染可读性；FFmpeg可选下载供应链、签名/hash和构建许可证。
- API ASR端点支持格式/大小/时间戳/保留政策及外发授权；只支持已验证协议。
- 事件模型可分发轻运行时与准确预处理。找不到合适制品时明确events暂不可用，不背着用户装TF。
- 具体benchmark小集依然要核实。本稿是设计修改，非冻结或开工授权。
