# 第一版验收基线

2026-11-03 用户明确同意此标准并授权按Goal推进实现与验证。批准标准不等于声称标准已满足；工程/效果须分别留证。

## A 工程硬门槛（全部满足）
- 既定特征按规格输出，方法/单位/有效参数/范围/缺失原因清晰；合成信号验证RMS/峰值/频率/声道/时间及误差容限。
- 图像实际进入Agent输入，轴/参考可读；可调参数真实生效，无效参数明确报错。
- 支持多轮局部检查，结果/缓存不会混淆音频、范围或参数。
- 未配置/模型缺失/解码失败/超时/取消区分；不伪装静音或完整处理。
- 权限检查、无擅自下载/外发、不执行音频指令、取消清理均通过。
- 声明平台干净安装可用，默认不要求编译/Python/TF/Torch/模型；缺ASR基础功能仍可用。
- 至少一条实测ASR路径；宣称事件标签能力则须一条实际可用分类路径，骨架不算完成。
- 文档涵盖安装/配置/升级/卸载，实测报告安装包/依赖闭包/首用下载/模型缓存；依赖核实后、安装测评前固定体积预算，不能测后移动门槛。

## B 效果门槛
- 固定同一主模型、同一MMAU公开小集：工具组正确率比无音频基线至少高10个百分点。
- 音乐、人声、其他声音三域均正向增益，不能只靠转写提高总分。
- 受支持且预检/后端正确配置题目运行完成率≥95%；失败题保留在整体成绩中。
- 不超批准调用/费用/时长预算；报告总量、延迟、失败、样本数、逐题差异和不确定性。
- 静音/替换音频/错误输入控制不得出现系统性伪造或忽略音频。

## C 工具面选型
聚合/正交拆分共享特征实现、后端及资源/推理预算；允许Agent自主迭代。先比较正确率/三域，再比较token/提取/API/延迟/错误。差异不明确优先简单可维护。此为选型依据，不要求某面胜出。

## 授权边界
已授权按Goal推进实现、工程测试、隔离开发验证及准备公开benchmark评测。付费API、音频外发、需要更宽文件权限的安装/写入仍单独请求；不得读凭据本体或私人录音，不生产安装/发布/打tag。原设计文档“禁止任何实现”已被本轮直接授权替代。
