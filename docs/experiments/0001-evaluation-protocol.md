# 实验协议：到底有没有听见，而不是会不会描述

状态：设计草案，未执行。依赖[路线 ADR](../adr/0001-audio-understanding-paths.md)。本轮不下载语料/权重、不调用接口。

## 1. 先定义问题
H1：原生音频问答能够在音乐、人声、环境三域均明显优于 ASR-only。
H2：结构化事件/音乐特征能补足原生模型的特定缺陷，而非只让回答更长。
H3：16k/mono/切片会损失某些任务的信息；不能未经比较作为统一预处理。
H4：频谱图在部分声学任务有益，但不能默认替代原始音频语义。
允许否定全部假设；不以必须发布插件为实验目标。

## 2. 语料与参考答案
第一轮筛选：24个原始素材，分音乐/人声/环境声/混合声四组，各6个，时长10–30秒；每段3道冻结问题，总72题。
每组3个开发素材、3个封存测试素材；所有同源派生、混音、裁剪必须留在同一分区。开发可改提示词，测试只在候选锁定后执行一次，不拿测试结果调参。

| 组 | 覆盖要求 | 问题举例 |
|---|---|---|
| 音乐 | 打击/弦/键盘/电子，独奏与混合，节奏或段落变化 | 哪类乐器可听？什么发生变化？速度感/强弱如何？ |
| 人声 | 中文/英文，清晰/噪声/重叠，表达变化 | 内容是什么？几路可分辨人声？语速强弱怎样变化？ |
| 环境 | 脚步/敲击/水/动物/机械，近似易混声 | 什么事件？何时发生？哪些来源不能确定？ |
| 混合 | 人声+音乐，音乐+环境，多事件遮蔽 | 前景背景是什么？事件先后如何？遮蔽了什么？ |

另建8个控制素材：数字静音、低电平噪声、近静音、音频内容反事实配对、误导文件名、立体声左右交换、反相声道、含口头提示注入。近静音不能简单当绝对静音；幅度阈值/人工可听参考先定。
长音频阶段：另6段2–10分钟（每类至少1段），用已标注短事件插入不同位置，核对漏检、跨窗关系与覆盖声明。长片不是把同一短片循环后声称泛化。

来源候选：自制合成信号/自有乐器录音/明确开放许可语料；FSD50K/ESC-50、MUSDB等仅是检索线索，逐文件核对许可、用途和外发限制后才能使用。不默认下载，不用私人录音，不默认网上歌曲可外发。
参考标注：先不看模型输出，由两位标注者独立听并列核心事实、允许变体、不可判定项、事件边界；分歧仲裁。不把元数据歌名当“听出来”真值；感受类只做主观维度报告，不与客观事实混为准确率。

## 3. 阶段与最小调用量
E0 离线准备：核来源/许可/清单、参考答案、工具链和硬件，只在获准后采集。
E1 接口/证据依赖：每个候选最多6次小请求；真实短音频、替换音频、静音、缺音频、格式错误、取消各一次。不能只看200返回；同问题换声音要出现对应变化。缺音频必须由验证层拒绝或明确说明不足，不伪造结果。
E2 质量筛选：A 原生音频至多2个具体后端；B ASR-only基线；C ASR+事件/音乐特征；D 时频图视觉代理。四条路线至多5个配置×24段=120次逻辑分析（每次回答同一组3题）；32个控制分析上限，控制条件按适用路线分配并事先冻结。接口请求、重试、分窗实际调用另行累计，不能拿逻辑次数当费用。
E3 消融：优胜配置选8段做保留原率/后端要求重采样/16k、stereo/mono对照；只在后端接受的格式上做有效比较。后端内部转换未知则写未知，不能将上传stereo当模型真利用双声道。按控制变量分开试，禁止全因子爆炸。
E4 长音频：至多2个入围配置×6段；比较全量（支持才做）与固定窗+重叠两条件，记录跨窗错配。

每阶段必须有前一阶段报告和授权才能继续；样本数/限额是计划上限，不是已批准预算。

## 4. 统一评估
- 每题核心事实给0/1/2分：0错误或无答案；1部分正确；2满足冻结关键点。分域宏平均/2，禁止音乐差用台词分补偿。
- 幻觉率：无证据且错误的实质陈述数/全部可检验实质陈述数；拒答不算幻觉，但答复覆盖率单列。
- 时间定位：对参考事件算起止绝对误差及区间IoU；无时间能力的路线标不支持，不强造秒数；漏事件计召回损失。
- 转写仅在人声子任务算WER/CER；音乐的BPM只对明确稳定节奏参考算误差，半拍/倍拍容忍规则先冻结。
- 主观音乐/音色/情绪描述盲评相关性与有据性，不能将心理状态当事实。
- 链路另报：成功/拒绝/超时/取消、实际请求数、端到端延迟p50/p95、处理/排队/加载时间、内存峰值、上传字节和账单费用；不同硬件本地结果不直接横比速度。
- 输出顺序打乱、匿名后端，由人工盲评；模型裁判只能辅助，不作唯一裁判。
- 所有错误和失败纳入结果；72题不是72个独立素材，区间估计按原始素材聚类。小样本只筛选，不宣称统计性冠军。

## 5. 建议门槛（待确认，不是效果承诺）
- 音乐/人声/环境/混合各域得分≥0.75；答复覆盖率各域≥0.80；实质幻觉率≤0.05。
- 8个控制场景均无严重伪造/指令执行；静音不编造声音；无依据身份/歌名不作确证。
- 若输出时间戳：适用事件至少80%落在人工参考边界±1秒，且同时报告召回；不支持则明确降级，不掩盖。
- 长音频已标关键事件召回≥0.80，范围报告真实；其余不得自称“完整听过”。
- 性能和金额先测量，用户给预算再冻结SLO，不凭空设某秒以内。
- 任一分域未过就不能称通用听觉能力；可追加最小针对性实验，不能偷偷缩范围发布。

## 6. 证据记录
每次：run_id、素材hash、分区、许可/同意、问题版本、期望答案版本、模型/版本/endpoint别名、参数、prompt hash、格式/预处理/分窗、覆盖范围、原始响应、错误、时延、用量、成本、评分者与争议。
日志不得包含key/cookie/鉴权header。云端只在明确同意后外发最小音频窗；失败不自动换服务。
候选接口能力清单必须先写清：输入格式、时长/大小限制、声道、原声问答/仅ASR、时间精度、存储/保留政策。未知项不留成“支持”。

## 7. 停止规则
超过批准预算/外发范围立即停止；端点忽略音频、静音持续幻觉、控制提示注入成功，先修验证设计再跑批量。不因成功请求就开发插件。
