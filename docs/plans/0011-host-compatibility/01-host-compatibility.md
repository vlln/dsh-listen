## 范围与步骤

用户批准以删除过度实现为优先，不新增自定义授权层。删除host中的cwd containment和processPath直通，使用现有fs.resolve/readBytes限制读取，暂存后交给解码器。现有snapshot root仅约束私有副本，不再定义用户可读文件边界。短ID在当前会话文件引用中匹配，至少8位十六进制摘要，可带sha256:，歧义显式失败；不扫描全局仓库。

评测保留题目/选项原文及顺序，按题工作区批量执行；删除零基索引/JSON输出契约，原始final文本写model_output，预算由运行层控制。官方评分字段与有限离线对照见[evaluation说明](../../../evaluation/README.md)。不重新运行旧授权9题，不启动真实主模型请求，不重启3187体验实例。

## 剩余边界

采用宿主readBytes不等于完整OS强制沙箱认证；宿主后端的身份/并发读取语义仍由宿主负责。256MiB的readBytes会分配有界缓冲，不声称流式零拷贝。现有临时副本/解码快照存在重复复制，本次不另起重构。子进程后代回收与平台验收仍未完成。旧本地产物和历史预检结果不自动改写，新协议准备与真实评测需未来明确批次授权。
