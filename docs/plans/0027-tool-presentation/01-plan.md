## 用户要求

工具只呈现如实执行结果，删除固定限制声明；数字自适应短小数或科学计数法。

## 实施范围

1. summary/full 的模型可见结果递归删除 limitations、score_semantics、detail_guidance；不转移到 persona。
2. 非整数以5位有效数字序列化，选择较短的小数/科学计数形式；整数计数保留。
3. 保留实际状态、错误、单位、方法、覆盖范围、截断计数、转写原文及图片引用。
4. 原始执行报告、计算、缓存不舍入；不下载、不做付费评测，不擅自重启人工站。
5. 测试覆盖两种呈现、嵌套过滤、不变性及数字极值。
